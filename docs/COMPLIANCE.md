# 安全与合规说明

迁签审台被设计为**离线、只读、静态**的迁移评审工具。本文件说明运行边界、数据处理方式与已知限制，便于在受控环境中评审和部署。

## 1. 离线运行

- 运行期不发起任何网络请求。
- 不依赖 CDN、云服务、外部 API、远程规则源、远程数据库或在线字体/图片。
- 依赖仅来自本地已安装的 `sqlglot`、`PyYAML` 与 Python 标准库。
- 生成的 HTML 为自包含文件：内联 CSS，无脚本、无外链、无外部图片或字体。
- 测试全部离线运行，不需要网络、数据库或服务端。

## 2. 不连接、不执行、不修改

- 不连接任何数据库，不创建连接串，不探测端口或服务。
- 不执行迁移、回滚、DDL、DML、权限变更、事务或任何 SQL。
- 不调用数据库客户端、驱动、ORM 或外部 SQL 服务。
- 只读输入迁移目录；不修改、移动、删除、重命名或格式化原始迁移文件。
- 输出仅写入用户指定的报告目录与 SQLite 台账路径。
- 不自动重写、修复、补全、重排或生成可执行 SQL；建议字段仅为人工可读文字。

## 3. 凭据与合成数据

- 仓库中的代码、配置、fixture、规则、测试与报告不包含真实密钥、真实凭据、真实连接串、真实公司名、真实域名或真实目标地址。
- fixture 使用 `demo_*` 等明显合成标识；示例原因与豁免均为演示文本。
- 工具不要求用户提供数据库账号、密码、令牌或连接地址。
- 报告不写入环境变量、主机名、用户名或绝对目录；复现命令优先使用相对路径。
- 如果用户在真实迁移上运行工具，报告仍可能包含截断后的对象名、文件名与证据片段。此类输出应按内部代码/架构资料管理，不应上传到未授权的公开位置。

## 4. 审计留痕而非审计规避

- 工具用于发现迁移风险、保留评审证据，不用于绕过数据库安全控制、提升权限、隐藏变更或规避审计。
- 不可逆变更标记 `-- qianshen: irreversible approved-reason="..."` 只表示“已人工确认”，不会跳过规则、不会降低严重级别、不会删除发现。
- 豁免必须有原因和到期日，并继续出现在报告与台账中；过期豁免不会被静默忽略。
- 已豁免发现、过期豁免、解析降级警告与输入错误均单独留痕，便于事后复核。
- 退出码由活跃发现与阈值决定，不提供“强制通过”或隐藏阻断项的参数。

## 5. 数据最小化

- 不采集遥测、使用统计、运行环境指纹或远程日志。
- 不复制完整 SQL 原文到报告；证据截断至 180 字符，建议截断至 240 字符。
- 台账保存文件相对路径、SHA-256、语句摘要、发现与规则快照，供本地审计使用。
- 运行 ID 与配置/规则/输入摘要用于复现，不包含机器绝对路径。
- 报告与台账保留在用户指定的本地路径；工具不主动删除或上传。

## 6. 输入安全

- 仅扫描 `migrations_dir` 下的 `.sql` 文件，按配置忽略目录、通配符与路径。
- 文件按字节读取并计算 SHA-256，再以 UTF-8 解码；解码失败记录错误并以空文本继续，不中断其他文件。
- SQL 仅由 `sqlglot` 静态解析；解析失败时使用保守令牌匹配，不执行、不拼接、不求值。
- 规则中的 `sql_regex` 只用于静态文本匹配，不执行任意代码。
- 规则、配置、豁免、baseline 的结构均有校验；未知规则字段、未知检查器、重复 ID、无效日期会以退出码 2 拒绝运行。

## 7. 确定性

- 时钟由配置 `clock` 或 `--now` 注入；默认固定为 `2026-01-01T00:00:00Z`。
- 文件 mtime 不参与逻辑判断与输出，仅保留固定占位符。
- JSON 键顺序、发现排序、运行 ID、报告内容与台账主键记录均可复现。
- 相同输入、配置、规则与工具版本产生相同的报告字节内容和运行 ID。
- 不依赖随机数、当前日期、时区、网络状态或环境变量做业务判断。

## 8. 已知限制

- 静态分析无法证明迁移在真实数据库上成功、可回滚或数据可恢复。
- 方言覆盖取决于 `sqlglot` 的能力；不支持形态会降级，并以低置信度呈现。
- 回滚配对基于对象键启发式，不覆盖触发器、存储过程、分区、数据回填语义等全部情况。
- 幂等性分是启发式指标，不是事务隔离或并发安全证明。
- 大表清单由配置提供，不做真实表规模探测。
- 工具不替代人工评审、变更审批、备份校验或数据库发布流程。
